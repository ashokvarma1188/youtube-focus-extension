# 🎯 YouTube Focus Mode

> A productivity-focused Chrome Extension that removes YouTube distractions and helps students stay focused while studying.

---

## 🚀 Features

✅ Hide Comments  
✅ Hide Recommended Videos  
✅ Hide Shorts  
✅ Hide Notifications  
✅ Hide Subscribe Button  
✅ Focus Mode ON/OFF Toggle  
✅ Pomodoro Study Timer  
✅ Clean Popup UI  

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extensions API
- DOM Manipulation

---

## 💡 How It Works

This extension detects distracting YouTube elements using JavaScript DOM manipulation and hides them automatically.

Users can:
- enable/disable focus mode,
- use Pomodoro timer,
- reduce distractions during study sessions.
