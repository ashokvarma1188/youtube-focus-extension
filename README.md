# YouTube Focus Mode

A Chrome extension that helps students stay focused while studying on YouTube.

## Features
- Hide comments
- Hide recommended videos
- Hide Shorts
- Hide notifications
- Hide subscribe button
- Focus mode ON/OFF toggle
- Pomodoro timer

## Technologies Used
- HTML
- CSS
- JavaScript
- Chrome Extensions API

## How It Works
This extension removes distracting YouTube elements using DOM manipulation and provides a focus timer for productivity.
